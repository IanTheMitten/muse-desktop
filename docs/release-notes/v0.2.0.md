# Muse 0.2.0 (alpha)

Radio now follows the song you started it from, and Muse can tell you which songs are missing lyrics.

## New

- **Radio follows a curve.** Radio now plans each pick with the same engine that builds playlists, so it moves smoothly instead of drifting. A new **Lift** switch on the Muse page makes radio climb gradually toward lighter songs.
- **Calm, mid and energetic.** The mood picker now measures energy from the sound itself, so it works for every song with no lyrics needed.
- **Missing lyrics.** Home shows how many songs have no lyrics. Open the list to add lyrics, or mark a song as having no words.
- **Add lyrics from Radio.** When the song Radio started from has no lyric tags, Radio says so and offers to add lyrics.

## Changed

- Smart features no longer include the MiniLM and emotion models. Radio and recommendations use the audio and your listening instead of those models. Muse removes their files from the smart-features folder after the update, which frees disk space.
- The old mood mixes on Home are gone.
- Muse upgrades the smart features in place when every file is already on your computer, so you do not need to click Install again.
- Radio ignores late answers from a song you have already moved on from, and recovers if a request fails.

## Before you update

This update changes your library file in a way that cannot be undone. Muse converts it the first time you open 0.2.0. Copy `library.sqlite3` from your Muse data folder somewhere safe first, in case you ever want to go back to 0.1.6.

If you have smart features, the first launch after updating prepares the energy measurements in the background. Mood radio ignores energy until you reopen Muse once after that.

## Install

The builds are not notarized by Apple, so the first launch needs one extra step:

- **macOS:** download the zip, open it (Safari unzips it for you) and drag
  Muse into Applications. Open Muse; when macOS says it could not verify
  Muse, click Done, then go to System Settings → Privacy & Security and click
  Open Anyway. If macOS still says Muse is damaged, run
  `xattr -dr com.apple.quarantine /Applications/Muse.app` in Terminal and
  open it again.
- **Windows:** in the SmartScreen warning choose More info, then Run anyway.

Intel Macs get the app but no smart features.

## Known gaps

- Mood radio ignores energy until the first launch has prepared the measurements and you have reopened Muse.
- Media keys and the Now Playing widget are unverified.
- Some online sources may be unavailable.
