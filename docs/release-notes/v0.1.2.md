# Muse 0.1.2 (alpha)

A bug-fix release for Apple Silicon Macs.

## Fixed

- On Apple Silicon (M-series) Macs, the downloaded app no longer refuses to
  open with "Muse is damaged and can't be opened". The app is now signed as a
  whole, which Apple Silicon requires.

## Install

The builds are not notarized by Apple, so the first launch needs one extra step:

- **macOS:** open Muse. When macOS says it could not verify Muse, click Done,
  then go to System Settings → Privacy & Security and click Open Anyway.
  Download `Muse_0.1.2_aarch64.dmg` for an M-series Mac and
  `Muse_0.1.2_x64.dmg` for an Intel Mac.
- **Windows:** in the SmartScreen warning choose More info, then Run anyway.

Intel Macs get the app but no smart features.

## Known gaps

- After Reset to file tags, a song added from a plain link (with no record
  found) gets its album name back but stays grouped with the album you moved
  it into.
- Media keys and the Now Playing widget are unverified.
- Some online sources may be unavailable.
