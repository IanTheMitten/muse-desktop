# Muse 0.1.1 (alpha)

A bug-fix release.

## Fixed

- A song added with Add no longer drops out of its album into a one-song album
  (losing the cover) after Reset to file tags or Restore. It rejoins the rest of
  its record.
- When a download fails, Muse no longer updates yt-dlp a second time and
  re-downloads if it has just updated it.

## Install

The builds are unsigned, so the first launch needs one extra step:

- **macOS:** right-click the app and choose Open.
- **Windows:** in the SmartScreen warning choose More info, then Run anyway.

Intel Macs get the app but no smart features.

## Known gaps

- After Reset to file tags, a song added from a plain link (with no record
  found) gets its album name back but stays grouped with the album you moved
  it into.
- Media keys and the Now Playing widget are unverified.
- Some online sources may be unavailable.
